# 太鼠達人 🐭

辦公室養貓專用的逗貓網頁：螢幕上一隻紅老鼠會自己亂竄、停下來抖、偶爾吱吱叫，給主子拍。

**▶ 玩：https://leolin310148.github.io/nezumi-no-tatsujin/**

## 玩法

- 按「開始逗貓」會進全螢幕、游標會藏起來
- 點到（或貓拍到）老鼠就算抓到，老鼠會逃出畫面再從別處冒出來
- 可選老鼠速度、數量（1～3 隻）、背景音樂、吱吱聲

| 按鍵 | 功能 |
| --- | --- |
| `M` | 手動遛鼠：老鼠跟著游標走 |
| `1` `2` `3` | 速度：悠哉／正常／閃電 |
| `S` | 吱吱聲開關 |
| `F` | 全螢幕 |
| `Esc` | 回首頁 |

純前端、無建置步驟，直接用任何靜態伺服器開 `index.html` 就能跑（`python3 -m http.server`）。
